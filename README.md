# Gaussian Bench

Personal DSP and embedded-systems workbench.

## Goal

Gaussian Bench is a personal engineering project for exploring:

- digital signal processing
- numerical computation
- embedded systems
- signal acquisition
- filter design
- code generation
- hardware verification

## v0

The v0 goal is:

> Capture a signal, design a filter, generate C code, run it on hardware, and verify the hardware output against the C# reference model.

## Current milestone

Week 1 — Complex numbers and project scaffolding.

- C#
- .NET 10
- xUnit

- GitHub Actions
